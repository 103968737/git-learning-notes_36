# 01 环境准备

目标：在开始部署前，确认机器满足最低要求，并装好 Docker（或 Ollama），避免后面把环境问题误判成模型问题。

## 1. 硬件底线

| 项目 | 最低 | 推荐 | 说明 |
| --- | --- | --- | --- |
| 内存 | 16 GB | 32 GB | 7B 模型走 CPU 推理时，内存占用约 5～8 GB |
| 显存 | 无（纯 CPU） | 8 GB+ | 显存决定能跑多大模型、有多快 |
| 磁盘 | 20 GB 空闲 | 60 GB+ | 单个 7B 模型约 4～5 GB，多下几个很快见底 |
| CPU | 4 核 | 8 核以上 | 纯 CPU 推理时是主要瓶颈 |

没有独立显卡也能跑，只是 7B 模型的速度会降到每秒几个字；先用 1.5B～3B 的小模型体验更合适。

## 2. 操作系统与虚拟化

### Windows 10/11

1. **开启虚拟化**：任务管理器 → 性能 → CPU，确认「虚拟化：已启用」。若显示已禁用，需要在 BIOS/UEFI 中打开 `VT-x`/`AMD-V`。
2. **安装 WSL 2**（Docker Desktop 的后端）：

   ```powershell
   wsl --install
   wsl --set-default-version 2
   wsl --update
   ```

3. **安装 Docker Desktop**：

   ```powershell
   winget install Docker.DockerDesktop
   ```

   安装后启动 Docker Desktop，等托盘图标变为运行中，执行 `docker version` 确认能连上 daemon。
4. **NVIDIA 显卡**：安装最新版 Game Ready / Studio 驱动即可，**不需要**在 Windows 里单独装 CUDA Toolkit（Docker 镜像自带运行时）。

> Hyper-V 与部分安卓模拟器（如旧版雷电、夜神）会争抢虚拟化功能；如果 Docker 起不来，先关闭这类模拟器的 Hyper-V 兼容模式。

### macOS

```bash
brew install --cask docker
open -a Docker
```

Apple Silicon 上 Docker 走虚拟化层，推理性能不如原生 Ollama，建议直接用 `brew install ollama`。

### Linux

```bash
# Docker
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER   # 重新登录后生效

# NVIDIA 容器运行时（有显卡时）
sudo apt install -y nvidia-container-toolkit
sudo nvidia-ctl configure --runtime=docker 2>/dev/null || sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
```

## 3. 网络与代理

- Ollama 拉取模型走 `registry.ollama.ai`，Docker 拉镜像走 `docker.io` / `ghcr.io`，两者都需要能访问外网。
- 公司或校园网经常拦截大文件下载，表现为 `pull` 卡在某个百分比后超时；可切换热点重试，或给 Docker 配置代理（Docker Desktop → Settings → Resources → Proxies）。
- 国内访问 GitHub 不稳定时，Open WebUI 镜像 `ghcr.io/open-webui/open-webui:main` 可能拉取失败，可改用代理或 GitHub 加速镜像站。

## 4. 磁盘规划

| 内容 | 大约占用 |
| --- | --- |
| Docker 镜像（ollama + open-webui） | 5～8 GB |
| 每个 7B 模型（Q4） | 4～5 GB |
| 向量模型 `nomic-embed-text` | 约 0.3 GB |
| WebUI 数据（对话记录、知识库） | 随使用增长 |

Docker Desktop 的磁盘镜像默认放在 C 盘，空间紧张时在 Settings → Resources → Advanced 中把磁盘映像位置改到其他盘。

## 5. 一键自检

```powershell
cd ai-local-deploy
.\scripts\check-env.ps1
```

脚本会检查：内存与磁盘、显卡型号与显存、`docker` / `ollama` 是否安装、`11434` / `3000` 端口是否被占用，并给出「推荐跑多大的模型」的结论。

## 6. 装完后的验收清单

- [ ] `docker version` 能同时输出 Client 和 Server 信息
- [ ] `docker compose version` 输出 v2 版本号
- [ ] `nvidia-smi`（有 N 卡时）能看到显卡和驱动版本
- [ ] `.\scripts\check-env.ps1` 全部为「通过」或可解释的「跳过」
- [ ] 磁盘剩余 ≥ 20 GB
