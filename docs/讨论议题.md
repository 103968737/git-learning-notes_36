# 讨论议题

> 下面 5 个问题是在实际部署中真实存在的分歧点，欢迎在 [Issues](../../issues) 里补充你的硬件配置和实测数据。
> 发起方式：新建 Issue，标题以 `[讨论]` 开头，或用「功能建议」模板。

## 议题 1：8 GB 显存，选 7B-Q4 还是 14B-Q3？

- **背景**：8 GB 显存是入门独显的常见配置，7B-Q4（约 4.7 GB）跑得舒服，14B-Q3（约 6.5 GB）能塞下但质量有损。
- **讨论点**：同样任务下，14B-Q3 的实际效果是否稳定优于 7B-Q4？长上下文时 KV Cache 会不会把 14B 挤出显存？
- **本项目做法**：默认推荐 `qwen2.5:7b`（Q4_K_M），原因见 [02-模型选择与量化](../ai-local-deploy/docs/02-模型选择与量化.md)。
- **希望你补充**：你的显卡型号、两个模型各自的 tokens/s、显存峰值。

## 议题 2：Windows 上原生 Ollama 与 Docker Desktop 怎么选？

- **背景**：Docker 方式能一键得到「服务 + 界面」，但依赖 WSL 2 与虚拟化；原生 Ollama 更轻，但没有 WebUI。
- **讨论点**：课堂/机房环境通常不允许开 WSL 或 Hyper-V，这时候哪种方案更现实？
- **本项目做法**：两种都提供，Docker 为默认，原生作为兜底。
- **希望你补充**：你所在环境的限制，以及实际启动耗时。

## 议题 3：本地 RAG 的切块大小与 top-k 怎么定？

- **背景**：`examples/rag_demo.py` 默认按 500 字切块、召回 top-4，这是经验值而非实测结论。
- **讨论点**：中文文档按段落切还是按标题切更好？top-k 过大是否会让模型被无关片段干扰？
- **本项目做法**：按空行分段并合并到约 500 字，top-k 默认 4。
- **希望你补充**：你用自己的文档试出的最佳参数，以及回答准确率的变化。

## 议题 4：AMD 显卡值得投入支持吗？

- **背景**：本项目文档以 NVIDIA 为主，AMD 在 Windows 上的 Ollama 支持有限，多数情况会回退到 CPU。
- **讨论点**：是补一份 AMD 的 ROCm 部署说明，还是明确写「暂不支持、建议用 CPU 小模型」？
- **本项目做法**：暂未支持，在常见问题里说明会回落到 CPU。
- **希望你补充**：你有 AMD 显卡的实测结果吗？能跑通的话欢迎补文档。

## 议题 5：WebUI 默认关闭登录，边界在哪？

- **背景**：`docker-compose.yml` 里 `WEBUI_AUTH=false` 是为了本机试用方便。
- **讨论点**：一旦把端口暴露到局域网，没有登录的 WebUI 等于把模型和对话记录公开；默认值应该更保守吗？
- **本项目做法**：默认关闭，文档标注「多人/局域网请改 true」。
- **希望你补充**：你更希望默认安全还是默认方便？理由是什么。
